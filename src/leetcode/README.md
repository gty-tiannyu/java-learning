## 为什么一题一个文件夹

两道题的代码里都有 `class Solution`。如果把它们放在同一个文件夹（也就是同一个包）下，
Java 会报「类重复」。每个文件夹里写一行 `package leetcode.p000X;`，
它们就各自待在自己的包里，互不干扰，整个项目也能一次编译通过。

## 提交到力扣时的用法

1. 打开对应文件夹的 `Solution.java`
2. **删掉第一行** `package leetcode.p000X;`
3. 其余内容原样复制到力扣的代码框里（类名保持 `Solution`）
